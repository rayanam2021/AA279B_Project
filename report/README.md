# AA279B Project Report

`report.tex` follows the CVPR two-column template structure, using the
official `cvpr.sty` in this folder. Figures are in `figures/` (generated by
`examples/demo_scp_recovery.py --screenshot` and `examples/sweep_recovery.py`;
the sweep PNGs are copied from `results/`).

## Building

No LaTeX toolchain was found on this machine, so the easiest path is
[Overleaf](https://www.overleaf.com): upload `report.tex`, `cvpr.sty`, and the
`figures/` folder, and compile with pdfLaTeX.
